# Weekend Adventures
This is the web design for 'Weekend Adventures' a page designed for hiking groups every weekend
#
Weekend Adventures is a simple and modern landing page created with HTML and CSS for promoting weekend hiking events and language exchange activities.

The website allows visitors to learn about the events, see the participation cost, and contact the organizers directly through WhatsApp to reserve their spot and receive information about the next hiking destination.

---

## Features

- Responsive landing page
- Modern outdoor-inspired design
- Hiking and language exchange sections
- WhatsApp reservation button
- Event pricing section
- Safety disclaimer included
- Mobile-friendly layout
